# 1-6-3. 복습 과제 — URL Shortener 배포

## 시나리오

!!! note "팀장으로부터 슬랙 메시지가 왔습니다"
    **[팀장]** 오늘 오후 마케팅팀에서 사내 단축 URL 서비스 요청이 들어왔어요.
    개발팀이 코드는 다 짜놨고, 인프라 배포는 우리 팀 담당이에요.
    오늘 안으로 VM에 올려주실 수 있나요? **제한 시간 2시간입니다.**

    소스 코드 repo: [https://github.com/skilleat-labs/url-shortener-lab](https://github.com/skilleat-labs/url-shortener-lab)

    Dockerfile이랑 배포 가이드는 없어요. 개발팀이 기술 정보만 인수인계했습니다.

명령어를 외우는 것이 아니라, **어디 가면 답이 있는지** 찾는 능력을 발휘할 차례입니다.

## 요구사항

### 개발팀 인수인계 기술 정보

| 항목 | 내용 |
|------|------|
| 언어 | Python 3.12 |
| 프레임워크 | FastAPI (uvicorn으로 실행) |
| 앱 실행 명령어 | `uvicorn app.main:app --host 0.0.0.0 --port 8000` |
| Dockerfile CMD 형식 | `CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]` |
| 앱 listen 포트 | 8000 |
| DB | PostgreSQL 16, DB 이름: `shortener` |
| DB 연결 환경변수 | `DATABASE_URL` (형식: `postgresql://USER:PASSWORD@HOST:5432/shortener`) |
| DB 초기화 스크립트 | repo 내 `postgres/init.sql` |

### 운영 요구사항

!!! warning "구현 방법은 스스로 결정하세요. 아래는 **무엇을** 해야 하는지만 기술합니다."

1. **데이터 영속성** — 컨테이너 또는 호스트가 재시작되어도 기존 단축 URL이 동작해야 합니다.
2. **네트워크 보안** — DB는 외부에서 직접 접근할 수 없어야 합니다. (보안팀 요구사항)
3. **자동 복구** — 컨테이너가 비정상 종료되면 자동으로 재시작되어야 합니다.
4. **상태 확인** — 서비스가 정상인지 외부에서 확인할 수 있어야 합니다.
5. **이미지 보관** — 빌드한 이미지는 반드시 ACR(`skilleatlab.azurecr.io`)에 push해서 보관해야 합니다.

## 완료 기준

과제가 완료되면 아래 3가지를 직접 검증하고 강사를 불러주세요.

- [ ] **1. 단축 URL 생성** — 브라우저에서 본인 VM IP로 서비스에 접속해 단축 URL을 생성할 수 있다.
- [ ] **2. 리다이렉트 및 클릭 수** — 생성한 단축 URL로 접속하면 원본 URL로 이동하고, 클릭 수가 올라간다.
- [ ] **3. 재부팅 후 데이터 유지** — `docker restart` 또는 VM 재부팅 후에도 기존 단축 URL이 동작한다.
- [ ] **4. 네트워크 보안 검증** — 호스트에서 DB 포트로 직접 접속을 시도했을 때 연결이 거부되어야 한다.

    ```
    psql -h localhost -p 5432 -U postgres
    # → 연결 실패가 나오면 올바르게 구성된 것
    ```

- [ ] **5. ACR 이미지 확인** — `az acr repository list --name skilleatlab`에서 본인이 push한 이미지가 보여야 한다.
