    1-4-1. 도전 과제 — 내 홈페이지를 실시간으로 꾸며보자¶

    상황¶

    당신은 사내 신규 입사자 소개 페이지를 컨테이너로 띄우는 임무를 받았다. 그런데 디자인팀에서 "페이지 내용을 자주 바꿀 예정이니, 컨테이너를 매번 재시작하지 않아도 수정사항이 즉시 반영되어야 한다"고 요청했다.

    볼륨 마운트를 사용해 이 요구사항을 만족시켜야 한다.

    조건¶

    항목 값
    이미지 nginx:alpine
    호스트 포트 8080
    컨테이너 포트 80
    컨테이너 이름 my-page
    실행 방식 백그라운드
    볼륨 마운트 호스트 ~/my-website → 컨테이너 /usr/share/nginx/html

    STEP 1. 사전 준비¶

    호스트에서 작업 디렉토리를 만드세요.

    mkdir -p ~/my-website
cd ~/my-website

    index.html 파일을 작성하세요. 본인 이름과 좋아하는 색상을 넣으세요.

    nano index.html

    <!DOCTYPE html>
<html>
<head><title>홍길동 소개</title></head>
<body style="background-color: skyblue; text-align: center; font-family: sans-serif;">
  <h1>🙋 안녕하세요, 홍길동입니다</h1>
  <h2>좋아하는 색: 하늘색 💙</h2>
  <p>버전 1.0 — 처음 만든 페이지</p>
</body>
</html>

    STEP 2. 컨테이너 실행¶

    위 조건을 모두 만족하는 docker run 명령어를 작성하고 실행하세요.

    STEP 3. 첫 접속 확인¶

    브라우저에서 본인 VM의 192.168.x.x:8080으로 접속해 페이지가 정상적으로 뜨는지 확인하세요.

    STEP 4. 실시간 변경 ⭐ 핵심¶

    컨테이너를 절대 재시작하지 말고, 호스트의 ~/my-website/index.html 파일을 아래와 같이 수정하세요.

    <!DOCTYPE html>
<html>
<head><title>홍길동 소개</title></head>
<body style="background-color: hotpink; text-align: center; font-family: sans-serif;">
  <h1>🎉 페이지가 새로워졌어요!</h1>
  <h2>좋아하는 색: 핫핑크 💖</h2>
  <p>버전 2.0 — 컨테이너 안 끄고 바꿈!</p>
</body>
</html>

    저장한 뒤 브라우저에서 F5(새로고침) 만 눌러 변화를 확인하세요.

    완료되면 강사를 불러서 확인을 받으세요.
